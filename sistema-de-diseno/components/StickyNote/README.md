# StickyNote

Post-it. Nota corta pegada sobre la superficie.

```jsx
<StickyNote tone="pink" rotate={4}>Las buenas ideas empiezan aquí</StickyNote>
```

Máximo dos o tres por composición y con rotaciones distintas. Frase de 3–8 palabras. Nunca metas dentro un botón, un formulario ni contenido que tenga que ser accesible en orden: es un objeto decorativo con texto, no un contenedor.
