Botón de acción; úsalo para la CTA de una propuesta, un formulario o una pieza web.

```jsx
<Button variant="primary" size="lg">Agendar diagnóstico</Button>
```

Variantes: `primary` (Pink Paradise, la CTA por defecto), `secondary` (Deep Blue-Gray), `lime` (Light Lime sobre fondo oscuro), `outline` (borde ink, se invierte en hover), `ghost` (sólo texto rosa). Tamaños `sm|md|lg`. Nunca dos botones `primary` en la misma vista.
