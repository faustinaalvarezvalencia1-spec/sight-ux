# Highlight

Marcador sobre la palabra clave del titular.

```jsx
<h1 style={{font:'var(--type-title)'}}>Convertimos incertidumbre en decisiones de diseño que impulsan el <Highlight>crecimiento</Highlight>.</h1>
```

Una palabra (dos como máximo), una vez por titular. `lime` es el resaltado por defecto; `pink` sólo sobre superficie clara y con texto en papel. No resaltes texto de cuerpo: si hace falta énfasis ahí, es que el titular está mal escrito.
