# DiagnosisTrack

Vía metodológica de Sight — la columna vertebral de todo caso de estudio.

```jsx
<DiagnosisTrack steps={[
  {title:'Síntoma', body:'Caída de conversión en tienda propia.'},
  {title:'Causa raíz', body:'La promesa de marca no coincide con la experiencia.'},
  {title:'Tratamiento', body:'Rearticulación de propuesta y sistema visual.'},
  {title:'Resultado', body:'Ticket medio +18% en dos trimestres.'}
]} />
```

Cuatro pasos, siempre en ese orden y con esos nombres. `orientation="vertical"` para columnas estrechas.
